# 星轨助手 · Startrail Helper

面向《洛克王国：世界》的个人辅助工具，主要开发方向是 **Android 本地独立运行的 App**，同时保留 Windows 端 Python 原型。

安卓版通过无障碍服务获取游戏窗口截图，在设备本地进行中文文字和界面识别，再执行点击与滑动。日常运行不需要电脑、ADB 或持续连接 AI；开发时使用 ADB 安装、查看日志和验证画面。

> **当前为开发版。** 主要花种流程已有实测记录，但尚未完成全目标、全异常分支和长时间稳定性验收。请以实际游戏界面及本仓库的测试状态为准。

| 传说精灵完整捕捉与专用印记 | 已提供入口与资源限制，完整实战仍待验证 |
| 通用任务、自动刷异色 | 尚未实现完整流程，不能视为现有能力 |

## 已验证与限制

- Lenovo Y700（TB322FC）、Android 16、游戏横屏 3040 × 1904 上有花种两轮连刷成功记录；这不是全部最新分支均通过的证明。
- 修复选宠后核对过燃薪虫技能，聚能恢复到 10 后继续出招。
- 核对过一次实际紫星消耗：500 → 480，蓝星未被扣除。
- 规则检查覆盖资源选择、双向耗尽切换、未知余额、两种资源耗尽及 100 次技能循环。
- 最新奖励页修复通过故障截图回归，包括“捕捉 → 奖励”和“奖励页已关闭 → 确认世界”的状态切换；**最新修改后的完整实战复测尚未完成**。
- 不同目标、命定花种、力竭后恢复、资源真正耗尽、网络中断及长时间连刷仍需补充测试。
- 目前只包含燃薪虫的技能策略，不会自动推导所有宠物的克制和打法。
- 游戏更新、UI 缩放与设备分辨率可能影响识别；识别无法确认时可能暂停，需要查看日志或校准。

## 安卓使用方法

1. 自行构建并安装 APK，打开“星轨助手”。目前仓库不提供稳定版 APK 发布承诺。
2. 点击“启用无障碍”，由本人在系统设置中开启“星轨助手 · 游戏自动操作”。
3. 保持游戏横屏、屏幕亮着，并将燃薪虫放到配置对应的队伍位置。
4. 在助手中选择花种或传说模块，点击“读取当前列表”。
5. 从实时列表选择目标，设置次数、出战位置和捕捉消耗，再开始连刷。
6. 使用悬浮面板查看当前步骤，按需暂停或停止。首次测试建议只刷 1 次。

游戏需要在前台。锁屏、切换应用、系统取消触摸或无障碍中断会影响执行。无需 Root；本项目未通过读取游戏内存或修改协议来获得状态。

## 构建安卓版

需要 JDK 17 或更高版本，以及 Android SDK（Platform 35、Build Tools 35.0.0）。首次构建需要联网下载 Gradle、Android Gradle Plugin 和 ML Kit 依赖。已使用 Gradle 8.11.1、AGP 8.7.3 构建。

配置 `ANDROID_HOME`，或在 `android/local.properties` 中设置本机 `sdk.dir`。不要提交该本地配置文件。

Windows 下建议将仓库克隆到英文路径（例如 `C:\dev\startrail-helper`）。工程关闭了 AGP 的非 ASCII 路径拦截，便于中文工作目录构建，但第三方工具的路径兼容性仍以实际环境为准。

Windows PowerShell：

```powershell
cd android
.\gradlew.bat assembleDebug
```

macOS / Linux：

```bash
cd android
chmod +x gradlew
./gradlew assembleDebug
```

APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`。当前最低 Android 版本为 11（API 30），打包架构为 ARM64。跨设备兼容性未全部验证。

也可直接使用 Android Studio 打开 `android` 目录，等待依赖同步后构建。调试 APK 使用本机调试签名；不要将其当作已签名的正式发行版。

## 规则检查

无需连接游戏，使用 JDK 执行：

```bash
javac -d .policy-classes android/app/src/main/java/cn/startrail/helper/BattlePlan.java android/app/src/main/java/cn/startrail/helper/ResourcePolicy.java android/tests/PolicyChecks.java
java -cp .policy-classes cn.startrail.helper.PolicyChecks
```

App 内的 `LocalSelfTest` 是开发用截图回归入口。真实游戏截图没有随仓库发布；缺少截图时会跳过相应项目，不能将“跳过”视为“通过”。

## Windows 原型

电脑端保留在 `desktop/`，入口为 `control_panel.py`，仅适用于 Windows。依赖安装和限制见 [电脑端说明](desktop/README.md)。原机的 Python vendor 目录、Interception 驱动、SDK、JDK、缓存及个人配置均未上传，因此不能承诺换机后直接双击运行。

## 开发与反馈

欢迎提交 Issue 或 Pull Request。反馈问题时请提供：目标名称、设备与系统版本、卡住的步骤、脱敏日志，以及遮挡账号信息后的必要截图。请勿上传账号凭据、完整私人日志或签名密钥。

修改自动化状态机时，请同时检查成功退出、失败退出、暂停恢复和下一轮接续；图像识别改动需同时验证正例与负例。

这是非官方个人项目，与游戏运营方无关联。使用时请遵守游戏规则，并自行了解自动化使用的限制。游戏名称、文字和识别模板中的游戏元素，其权利归对应权利人；详见 [第三方说明](THIRD_PARTY.md)。
