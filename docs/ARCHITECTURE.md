# 安卓流程与测试边界

界面设置 → 无障碍截图 → 本地 ML Kit 中文识别 → 状态机判断 → 无障碍手势 → 下一帧确认。

主要文件：

- `MainActivity.java`：设置与列表、日志界面。
- `GameAccessibilityService.java`：窗口截图、手势和悬浮面板；任务代号变化后不执行旧延迟触摸。
- `Vision.java`、`TextTemplates.java`：全文与区域识别、少量 UI 文字模板、资源图标定位。
- `Engine.java`：导航、扫描、传送、靠近、选宠、战斗、力竭等待、捕捉、奖励、退出和恢复。
- `BattlePlan.java`、`ResourcePolicy.java`：与设备无关的规则。
- `LocalSelfTest.java`：本地截图回归，截图不随仓库分发。

目标按当前列表名称重新核对；不再仅凭粗略图像哈希把另一目标当成所选目标。无法识别的名称仍可能导致定位失败，需完善识别，而不是默认进入别的目标。

扫描成功后才替换已保存目录。资源未知时不授权切换到另一种资源。选宠需核对技能，技能发送后等待能量或界面反馈。奖励识别和返回世界是不同步骤，不能凭一个页面消失就计数成功。

当前未完成全设备、全目标的状态机验证。特别需要补充资源实际耗尽、网络故障、宠物力竭后 Boss 延迟倒下，以及奖励页变体的实测。
